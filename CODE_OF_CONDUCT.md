# Code of conduct

Be respectful, precise, and constructive. Discuss the content rather than the person. Security findings can be sensitive; protect affected organizations and do not publish operational details that create unnecessary risk.

Harassment, discrimination, doxxing, threats, and disclosure of private telemetry are not acceptable. Maintainers may edit or remove material that violates these expectations and may restrict participation when necessary.

Report conduct concerns privately to the repository owner through the contact method configured on the GitHub profile.
